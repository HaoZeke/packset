* Protocol

Name: =keep-testing-due_at-vs-lru=
Script: =scripts/keep_testing_vs_lru.py=
Same pack. Two arms. One delayed test.

- Pack: 64 lesson atoms, splice budget 8, Zipf s=1.2 queries.
- Encode at 2026-08-01T00:00:00.000Z.
- Interference: 168 hourly queries (seven days).
- Delayed test at hour 168. Tail = ranks 8..63 (56 atoms).
- LRU arm: recency cache of size 8. =evict_lru= drops oldest =lru_last=.
- Keep-testing arm: =schedule_review= / =is_due=. Queried due atom is
  pinned into the window and stretched on success. Scheduled atoms
  stay in the pack.
- Hit: the queried tail atom is in the size-8 window at test time.
