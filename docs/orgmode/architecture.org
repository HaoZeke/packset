#+title: packset architecture
#+options: toc:nil num:nil

One writer on loopback. Cards are files. Atoms are LMDB.
milli is a projection. Every agent is an HTTP client.

* Contract

- URL: =PACKSET_URL= (=INSIDE_MEMORY_URL= alias)
- Host: =127.0.0.1= only. Never =localhost=.
- Port: =8761= (=PACKSET_PORT=)
- Health: =packsetd ok=

* Split

| Crate / script | Role |
|---|---|
| =packsetd.py= | writer |
| =packset-core= | named fuse/diversify/decay panel, extract filters |

Host panel env: =PACKSET_FUSE= =PACKSET_DIVERSIFY= =PACKSET_DECAY=.
Default =borda= / =mmr= / =off=. Unknown names fail closed.
| =packset-client= | HTTP |
| =packset-milli= | search projection |
| =packset_tui= | Textual DataTable over GET /v1/atoms |

Clients do not open the LMDB.

* Review clock eval

=scripts/keep_testing_vs_lru.py= is the named keep-testing vs LRU
protocol (Hu 2025 p.59), =keep-testing-due_at-vs-lru-v2=. Same pack.
Same Zipf stream. Keep-testing arm is =recall= due-first plus
=schedule_review(recalled=True)= on a spliced due atom. LRU arm is
last-budget accessed ids. The metric is later-horizon splice tail
hit and interference tail slot rate. Last run:
=docs/orgmode/keep-testing-vs-lru.org=. SCORECARD Measured stays
empty until that script is executed.
