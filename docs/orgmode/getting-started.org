#+title: Getting started
#+options: toc:nil num:nil

Everything below runs against a scratch workspace and touches nothing else.
By the end you will have a pack that remembers two claims, ranks them, tells
you when to review them, and exports them for another seat.

* 1. Start the writer

#+begin_src console
$ packset ensure
PACKSET_URL=http://127.0.0.1:8761
$ export PACKSET_URL=http://127.0.0.1:8761
$ packset status demo
packset: up on 127.0.0.1:8761 (packsetd ok)
#+end_src

One process owns the store. A second =packsetd= on the same file refuses
to start and says who holds the lock.

* 2. Remember two claims

An atom is one claim in at most two sentences of at most twenty-five words
each. The pack refuses anything longer, and it refuses a tool dump outright.

#+begin_src console
$ packset remember --workspace demo "The lexical default is BM25+. It scored 0.635 hit@1 against 0.615 for BM25."
$ packset prefer --workspace demo "CombMNZ over RRF for fusing two ballots."
$ packset status demo | jq '.live_by_kind'
{ "lesson": 1, "preference": 1 }
#+end_src

Send the same lesson twice and you get the stored atom back, not a second
one. Send a contrary lesson and the old one's validity window closes.

* 3. Ask what the seat knows

#+begin_src console
$ curl -s "$PACKSET_URL/v1/search?workspace=demo&q=which+fusion" | jq -r '.hits[] | "\(.score)\t\(.kind)\t\(.text)"'
9.10	preference	CombMNZ over RRF for fusing two ballots.
#+end_src

The score is the panel's, not one scorer's. Two ballots, a prefix-and-edit
scan and BM25+ over an index, are fused by CombMNZ; see
[[file:explanation.org][Explanation]] for what was measured.

* 4. Review before you forget

Every new claim is due for review after one day.

#+begin_src console
$ curl -s "$PACKSET_URL/v1/atoms?workspace=demo" | jq -r '.atoms[] | "\(.due_at)\t\(.text)"'
2026-09-13T08:54:37.394Z	The lexical default is BM25+. ...
$ curl -s $PACKSET_URL/v1/grade -d '{"workspace":"demo","id":"<atom id>","recalled":true}' | jq .due_at
"2026-09-15T08:54:37.394Z"
#+end_src

A recalled claim comes back later; a lapsed one (=recalled:false=) comes
back sooner. With =PACKSET_DECAY=fsrs= on the writer, a claim you have not
reviewed also sinks in the ranking as its retrievability falls.

* 5. Hand the pack over

#+begin_src console
$ packset export --into /tmp/bag/data/atoms demo
2 atoms to /tmp/bag/data/atoms/demo.jsonl
#+end_src

The file is one JSON object a line, the same shape the store holds. Every
deed accession the atoms cite is printed on stdout, so a deed store can be
asked for the products in the same pipe:

#+begin_src console
$ packset export --into /tmp/bag/data/atoms demo | deedar export --into /tmp/bag/data/deeds -
#+end_src

The seat's =ljos handover= runs that pipe, seals the bag, and signs it.
